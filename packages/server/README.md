# @cleverforge/sanity-clever-forms-server

Framework-neutral server-side submission engine for CleverForms.

It provides active-form enforcement, field allow-listing, conditional visibility checks, server validation, rate-limit/spam hooks, storage contracts, and post-submission hooks.

Use it with `@cleverforge/sanity-clever-forms-sanity` or your own repository adapter.
