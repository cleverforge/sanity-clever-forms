# CleverForms Core field matrix

This is the canonical free/Core field catalog for the Sanity edition and should remain aligned with the other CleverForms CMS editions.

| Field | Core | Notes |
|---|---|---|
| Text | Yes | Single-line text |
| Textarea | Yes | Multi-line text |
| Email | Yes | Email validation |
| Phone | Yes | Telephone input |
| Number | Yes | Numeric input and min/max validation |
| Date | Yes | Date input |
| Time | Yes | Time input |
| Checkbox | Yes | Single boolean checkbox |
| Checkbox Group | Yes | Multiple checkbox choices |
| Radio | Yes | Single choice |
| Select | Yes | Single dropdown |
| Multiselect | Yes | Multiple dropdown choices |
| Heading | Yes | Display-only heading |
| Paragraph | Yes | Display-only explanatory text |
| Hidden | Yes | Hidden/default values |

## Core capabilities

Core also includes:

- multi-page forms
- required fields
- basic conditional visibility
- basic validation
- form status
- success messages
- redirect URL
- submission storage contract
- submissions viewer
- templates
- React renderer
- Studio plugin
- App SDK management app
- server-side submission validation
- Sanity Content Lake adapter

## Intentionally Pro

The following are not Core fields/capabilities:

- file uploads
- signatures
- calculations
- repeating fields/groups
- secure/private uploads
- advanced conditional branching
- Save and Continue
- PDFs
- payments
- CRM and external integrations
- advanced workflows
- analytics and abandonment
